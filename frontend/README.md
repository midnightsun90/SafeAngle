# SafeAngle frontend

Run `npm install` and `npm run dev`, then open http://localhost:3000.

This folder currently implements the first screen of `design/frontend-flow-v3.excalidraw`: company, worksite, and task information. The remaining screens are shown only as progress labels.

The visual tokens in `src/app/globals.css`, `InputField.tsx`, and `Button.tsx` come from [TailAdmin Free Next.js Dashboard](https://github.com/TailAdmin/free-nextjs-admin-dashboard), licensed under MIT. The original license is in `LICENSE`. The SafeAngle screen and its behavior were written for this project.
