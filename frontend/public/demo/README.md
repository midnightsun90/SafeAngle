## 촬영과 편집

2026-10-09 배포 웹에서 시연용 평가를 만들고 영상을 실제 저장한 뒤 OpenAI API 호출과 관절 확인, REBA 5점 계산까지 실행했다. 분석 대기 시간과 화면 전환 일부를 생략했다. 관절 제안 장면은 이번 실행의 실제 캡처를 사용했다.

결과 요약으로 이동한 뒤 자동화가 기대한 #summary-final 요소를 찾지 못해 녹화가 중단됐다. 마지막 상세 평가서 장면은 같은 날짜에 별도로 성공한 공개 배포 검증의 실제 캡처를 재사용했다. 따라서 한 번의 끊김 없는 시연 녹화가 아니라 실제 녹화와 실제 결과 캡처를 연결한 편집본이다. 원본 녹화와 실행 기록은 .local/demo-video/에 있다.

이번 녹화가 생성한 영상 및 DB 시연 데이터는 정리했다. 시연용 익명 Auth 계정은 남아 있다. 독립 전문가 채점과의 정확도 비교는 수행하지 않았다.
