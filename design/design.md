# SafeAngle 디자인 기준

## 방향

- 화면은 흰색 배경에 질문과 입력 항목을 가운데 모은다.
- [`reference.jpg`](reference.jpg)에서는 선명한 주황색 강조, 굵고 읽기 쉬운 글자, 넉넉한 여백만 참고한다.
- 검정 배경, 입체 리본, 홍보용 카드, 사진, 통계 블록은 평가 입력 화면에 사용하지 않는다.

## 시각 요소

| 요소 | 기준 |
| --- | --- |
| 배경 | 흰색 `#FFFFFF` |
| 본문 글자 | 진한 차콜 `#171717` |
| 보조 글자·선 | 회색 `#6B7280`, 연한 회색 `#E5E7EB` |
| 강조색 | 주황 `#FF5A14`. 현재 단계와 기본 버튼에만 사용 |
| 글자 | 굵은 제목과 간결한 본문. 작은 글자도 읽을 수 있는 크기 유지 |
| 입력칸 | 흰색 바탕, 얇은 회색 테두리, 완만한 둥근 모서리, 충분한 높이 |
| 버튼 | 주황색으로 채운 단일 기본 버튼 |

## 화면 구성

1. 상단에는 작은 SafeAngle 로고와 현재 단계만 둔다.
2. 본문은 가운데의 좁은 한 열로 구성한다. 제목 다음에 필요한 질문만 배치한다.
3. 필드에는 항상 이름을 표시하고, 한 줄에 입력칸 하나를 둔다.
4. 마지막 입력칸 아래에 다음 단계로 가는 버튼 하나를 둔다.
5. 장식, 사이드바, 다음 단계 미리보기, 불필요한 설명문은 넣지 않는다.

## 화면 1 내용

- 단계: `01 / 06` · `회사·작업 정보`
- 제목: `어떤 작업을 평가하나요?`
- 필수 입력: `회사명`, `사업장·작업 위치`, `공정·작업명`
- 기본 행동: `다음: 영상 올리기 →`

좁은 화면에서도 같은 순서로 세로 배치한다.
