# 촬영 자세 3종 초안과 REBA 확인 질문

기준: [평가축·점수표](evaluation-axes.md), [촬영 자세 후보군](video-posture-candidates.md), [README](../README.md). **REBA는 선택한 장면마다 별도 점수를 낸다.** 서로 다른 영상에서 목·팔·다리 값을 가져와 하나의 점수로 합치지 않는다. 아래 3종은 촬영 후보이며 최종 확정 전이다. 실제 작업에 없는 위험 자세를 만들 필요는 없다. 현재 [관절 추적 엔진](ENGINE.md)에는 REBA 계산 함수가 없으므로 아래는 점수 산출을 위한 설계다.

## 촬영 후보 3종

| 영상 | 한 작업 주기에 담을 장면 | 주로 확인하는 REBA 축 | 함께 관찰할 부담작업 유형 |
| --- | --- | --- | --- |
| 1. 낮은 곳에서 높은 곳으로 옮기기 | 똑바로 선 자세 → 무릎 아래 물건 집기 → 일어서기 → 팔을 뻗거나 어깨 위에 놓기. 실제로 반복하는 작업이면 한 주기를 더 담는다. | 목·몸통 앞굽힘/뒤젖힘, 다리 지지·무릎 굽힘, 위팔·아래팔 각도, 큰 자세 변화 (R02, R05, R08~R10, R14, R22) | 반복·머리 위 팔·굽힘·쪼그림·한 손 들기·중량물 들기·높이에 따른 들기·반복 들기 (B02~B05, B07~B10). 해당하는 것만 기록 |
| 2. 앉아서 손 작업하기 | 실제 업무의 키보드·마우스 또는 작은 부품 작업. 팔을 지지하는 구간과 지지하지 않는 구간, 손목과 손가락이 움직이는 구간을 담는다. | 앉은 자세, 목·몸통 각도, 위팔·아래팔·손목 각도, 팔 지지, 작은 동작 반복 (R02, R05, R08, R10, R13~R15, R21) | 키보드·마우스, 같은 동작 반복, 손가락 집기 (B01, B02, B06). 실제 업무에 해당하는 것만 기록 |
| 3. 측면에서 물체를 밀거나 당기기 | 실제 업무의 카트·물체를 옆에서 촬영한다. 작업자의 몸 방향과 촬영 방향을 일정하게 유지하고, 한쪽 다리에 체중이 실리는 구간은 실제로 발생할 때 담는다. | 평가할 팔의 자세, 다리 지지, 큰 자세 변화 (R01, R08, R10~R16, R22). 팔 벌림·손목 회전 등 측면에서 안 보이는 조건은 사람 확인 | 한 손 취급·과도한 힘 (B07, S07). 물체 무게만으로 밀기·당기기 힘을 확정하지 않음 |

손·무릎으로 충격을 주는 작업(B11)은 이 3종에 포함되지 않는다. 실제 작업에 있으면 **그 작업을 별도로 촬영하거나 조사자가 면담·현장에서 기록**한다. B11의 존재나 법적 해당 여부를 세 영상만으로 판단하지 않는다.

3번에서 몸을 크게 돌려 측면 관절 각도를 믿을 수 없는 구간은 채점하지 않는다. 실제 업무에 비틀림이 있으면 해당 여부를 사람에게 확인하고, 각도 측정이 가능한 장면을 따로 선택하거나 재촬영한다. 세 후보는 모든 자세 변형이나 부담작업 유형을 촬영만으로 입증하는 조합이 아니다.

## 점수 계산에 필요한 최소 질문 묶음

앱은 먼저 선택 장면에서 목·몸통·무릎·위팔·아래팔·손목 각도를 제안한다. 아래는 **영상만으로 확정할 수 없거나 확인이 필요한 점수 입력**이다. 여러 항목을 한 화면에 묶어 묻되, 점수에 필요한 독립 항목을 생략하지 않는다. 답은 `예/아니요/확인 불가` 또는 표의 선택지로 기록한다. `확인 불가`를 0점으로 바꾸지 않는다.

| 묶음 | 사용자에게 보일 질문 | 답변 → 점수 반영 | 평가축 |
| --- | --- | --- | --- |
| Q1. 장면·좌우 | **이 장면에서 평가할 팔은 어느 쪽인가요?** | 왼쪽/오른쪽. 해당 쪽 위팔·아래팔·손목을 같은 장면에서 사용한다. 좌우 부담이 다르면 보이는 쪽마다 별도 채점한다. 점수 가산 없음 | R01, R10~R16 |
| Q1. 목 보정 | **목을 돌리거나 옆으로 기울였나요?** | 없음 / 돌림 / 옆 기울임 / 둘 다. 하나 이상 있으면 목 점수 +1, 둘 다 있어도 +1 | R03~R04 |
| Q1. 몸통 보정 | **몸통을 비틀거나 옆으로 기울였나요?** | 없음 / 비틂 / 옆 기울임 / 둘 다. 하나 이상 있으면 몸통 점수 +1, 둘 다 있어도 +1 | R06~R07 |
| Q1. 다리 지지 | **이 장면은 앉음, 양발 지지·보행, 한쪽 다리 지지 중 무엇인가요? 발밑 지지면은 불안정한가요?** | 앉음 또는 양발 지지·보행이고 지지면이 안정적이면 다리 기본 1점, 한쪽 지지 또는 불안정한 지지면이면 기본 2점. 앉은 자세에는 무릎 굽힘 가산 없음. 현재 엔진에는 다리 지지 판정값이 없어 사람이 선택. 불안정 여부는 Q4에서도 재사용 | R08~R09, R22 |
| Q1. 팔 보정 | **평가할 팔을 옆으로 벌리거나 회전했나요? 어깨를 올렸나요? 팔을 받치거나 몸을 기대었거나, 팔 움직임에 중력의 도움을 받았나요?** | 세 항목을 각각 예/아니요로 확인. 벌림·회전 +1, 어깨 상승 +1, 지지·중력 도움 −1 | R11~R13 |
| Q1. 손목 확인 | **표시된 손목 굽힘·젖힘 구간이 맞나요? 손목을 옆으로 꺾거나 돌렸나요?** | 기본 구간 0~15°는 1점, 15° 초과는 2점으로 사람이 확인. 옆 꺾임·회전 중 하나 이상이면 +1, 둘 다여도 +1. 손목이 안 보이면 `확인 불가` | R15~R16 |
| Q2. 하중·충격 | **이 장면에서 확인한 물체 무게 또는 실제 가한 힘은 어느 범위인가요? 힘이 갑자기 커지거나 충격이 있었나요?** | 5 kg 미만 또는 이에 해당하는 힘 +0 / 5~10 kg +1 / 10 kg 초과 +2. 충격·급격한 힘 증가가 있으면 추가 +1 | R17~R18 |
| Q3. 손잡이 | **물체를 얼마나 안정적으로 잡거나 지지할 수 있었나요?** | 잘 맞는 손잡이와 안정적인 쥐기 +0 / 사용 가능하지만 이상적이지 않음 또는 다른 신체 부위로 적절히 지지 +1 / 쥘 수 있으나 불량 +2 / 손잡이가 없거나 안전하게 쥐기 어려움 +3. 잡거나 지지하는 물체가 **없는** 작업은 `해당 없음`으로 확인하고 가산 +0. `물체가 있는데 손잡이가 없음`과 구별 | R19 |
| Q4. 활동 | **같은 자세를 1분 넘게 유지했나요? 작은 동작을 분당 4회 초과 반복했나요(걷기 제외)? 자세가 빠르고 크게 바뀌었나요?** | 정지와 반복에 각각 +1. 빠르고 큰 자세 변화 또는 Q1에서 확인한 불안정한 지지면이 있으면 +1. 활동 점수 0~3 | R20~R22 |

Q1~Q4는 네 **화면 묶음**이다. 묶음 안의 판단까지 네 개로 줄인다는 뜻은 아니다. 다리 지지와 손목 구간도 선택한 장면마다 확인한다. 같은 작업·조건이 유지되는 여러 장면에는 Q2~Q4 답변을 재사용할 수 있지만, 장면이나 조건이 바뀌면 다시 확인한다. 최대 60초 영상에서는 `1분 초과 정지`를 영상만으로 확정할 수 없으므로 Q4에서 묻는다. 손목 회전과 목·몸통 비틀림·옆 기울임은 측면 2차원 영상만으로 자동 확정하지 않는다.

Q2에서 밀기·당기기처럼 물체 무게가 힘의 크기를 뜻하지 않는 작업은 **손에 가한 힘을 현장에서 측정하거나 확인**해 구간을 선택한다. 힘이 N(뉴턴)으로 기록됐다면 5 kgf ≈ 49 N, 10 kgf ≈ 98 N을 경계로 환산한다. 카트·물체의 무게를 밀기·당기기 힘으로 대신하지 않는다. 힘의 크기를 알 수 없으면 `확인 불가`이며, 가벼워 보인다는 이유로 +0을 선택하지 않는다. ([HSE의 밀기·당기기 힘 측정 안내](https://www.hse.gov.uk/msd/pushpull/assessment.htm))

## 영상 측정 실패 시에만 묻는 보충 질문

| 조건 | 보충 질문·선택지 | 평가축 |
| --- | --- | --- |
| 목·몸통 각도를 믿기 어려움 | **멈춘 장면에서 목·몸통은 어느 구간인가요?** [평가표의 부위별 점수 구간](evaluation-axes.md#1-1-부위별-점수와-가감)을 보여 주고 각각 선택. 판단 불가면 재촬영 | R02, R05 |
| 무릎 굽힘을 믿기 어려움 | **앉은 자세가 아니라면 무릎 굽힘은 30° 미만/30~60°/60° 초과 중 무엇인가요?** 다리 지지는 Q1에서 반드시 확인. 무릎 판단도 불가하면 재촬영 | R09 |
| 위팔·아래팔 각도를 믿기 어려움 | **멈춘 장면에서 평가할 쪽의 위팔·아래팔은 평가표의 어느 각도 구간인가요?** 판단 불가면 재촬영. 손목 기본 구간은 Q1에서 항상 확인 | R10, R14 |
| 작업을 대표하는 장면·평가할 쪽을 정하기 어려움 | **평가할 순간과 팔을 직접 선택해 주세요.** 둘 다 확인할 수 없으면 재촬영 | R01 |

보충 질문은 **확인 가능한 장면이 있을 때만** 점수 구간 선택에 쓴다. 보이지 않는 관절이나 추측한 각도로 확정 점수를 만들지 않는다. 영상 품질 판단(V01~V05)이 실패하면 재촬영 이유를 보여 준다.

| 평가표 ID | 채우는 방법 |
| --- | --- |
| R01 | 장면 선택과 Q1의 평가할 쪽 |
| R02, R05, R09~R10, R14 | 영상 각도 측정. 실패할 때만 보충 질문 또는 재촬영 |
| R08 | Q1에서 사람이 다리 지지 상태를 반드시 선택 |
| R15 | Q1에서 영상의 손목 추정 구간을 사람이 반드시 확인 |
| R03~R04, R06~R07, R11~R13, R16 | Q1의 부위별 보정 질문 |
| R17~R18 | Q2 하중·충격 |
| R19 | Q3 손잡이·지지 |
| R20~R22 | Q4 활동. 지지면 불안정 여부는 Q1 답을 재사용 |
| R23~R26 | 확인된 입력을 표 A/B/C에 넣어 계산한 점수와 조치 수준 |
| R27 | 장면·측정값·사람 입력·미확인 사유를 결과에 표시 |

## 계산·완료 조건

1. 선택한 **한 장면**의 R01~R22 입력을 영상 측정과 Q1~Q4(필요하면 보충 질문)로 채운다. 다리 지지와 손목 구간은 항상 사람 확인을 받는다. 해당 없는 가산 조건은 확인 후 `아니요`로 기록한다.
2. 목·몸통·다리의 기본 점수에 Q1 보정을 반영 → 표 A + Q2 = **점수 A**. 선택한 쪽의 위팔·아래팔·손목 기본 점수에 Q1 보정을 반영 → 표 B + Q3 = **점수 B**.
3. 점수 A와 B → 표 C + Q4 활동 점수 = **그 장면의 최종 REBA 점수**와 조치 수준. 표와 수치는 [평가표](evaluation-axes.md#1-reba-채점축)를 사용한다.
4. 세 영상 또는 여러 장면을 평가했다면 **장면마다 따로 계산**한다. 화면에 대표 점수를 하나 표시할 때는 선택한 장면의 점수인지, 분석한 장면 중 가장 높은 점수인지 명시한다.
5. 점수에 필요한 입력이 `확인 불가`이거나 영상 측정 실패를 보충 질문으로도 해결하지 못하면 **확정 점수 없음**으로 표시한다. 몸을 돌려 측면 측정이 불가능한 장면도 같다. 재촬영·현장 확인을 안내한다.

## REBA 점수 밖의 평가축

| 항목 | 처리 |
| --- | --- |
| 부담작업 B01~B11 | 하루 작업시간·횟수·무게·작업 지속기간 등의 실제 조건을 **별도 면담·현장 확인**으로 기록한다. 책의 오래된 법적 수치를 점수 질문에 섞지 않는다. REBA 점수에 더하지 않는다. |
| 조사표 S01~S16 | 공정·설비·작업량·접촉스트레스·진동·환경·증상·이력·개선계획 등은 조사표 초안에 남기고 조사자·근로자가 확인한다. REBA 점수에 더하지 않는다. |
| 영상 품질 V01~V05 | 앱이 사용 가능한 장면인지 먼저 판정한다. 법적 기준이나 REBA 가산점으로 사용하지 않는다. |

이 세 묶음까지 모두 완료했다고 표시하려면 영상 3종과 Q1~Q4만으로는 부족하다. **REBA 최종 점수의 완료**와 **유해요인조사표의 완료**를 별도로 표시한다. 근거: [REBA 채점 자료](https://ergo.human.cornell.edu/Pub/AHquest/Cornell_REBA.pdf), [산업안전보건기준에 관한 규칙 제657조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1028543325), [제658조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020911757).
