# 촬영할 작업 자세 후보군

| 후보군 | 이유 |
| --- | --- |
| 바닥이나 무릎 아래의 물건을 집어 허리 높이까지 드는 자세 | 들어 올리는 동안 몸통·목·다리의 굽힘과 팔 위치가 바뀐다. 책은 무릎 아래에서 드는 작업과 중량물 취급을 부담작업 사례로 다룬다. REBA 전신 자세 평가에 쓸 장면을 얻기 쉽다. (책 392, 701, 707쪽; README 「사용 흐름」) |
| 허리 높이의 물건을 어깨 위 선반에 올리는 자세 | 팔을 어깨 위로 들고 몸통·목 자세가 함께 바뀌는 장면을 볼 수 있다. 책은 머리 위 손·어깨 위 팔꿈치와 어깨 위로 드는 작업을 다룬다. (책 701, 705, 707쪽) |
| 팔을 앞으로 뻗어 물건을 들거나 옮기는 자세 | 몸에서 떨어진 물건을 잡을 때 팔·어깨·몸통 자세를 함께 확인할 수 있다. 책은 팔을 뻗은 상태의 들기와 과도한 힘을 유해요인 사례로 든다. (책 701, 707, 716쪽) |
| 허리를 굽힌 채 낮은 작업대에서 조립·분류하는 자세 | 일정 시간 유지되는 목·몸통 굽힘과 팔 위치를 볼 수 있다. 책은 목·허리를 굽히거나 자세를 바꾸기 어려운 작업을 다룬다. (책 701, 705, 716쪽) |
| 쪼그려 앉거나 한쪽·양쪽 무릎을 바닥에 대고 작업하는 자세 | 무릎과 다리 자세, 몸통 굽힘이 뚜렷하다. 책은 쪼그림과 무릎을 굽힌 작업을 별도 사례로 제시한다. (책 701, 706, 716쪽) |
| 같은 물건을 반복해서 집어 다른 위치에 놓는 자세 | 한 작업 주기 안에서 자세가 달라지는 순간을 비교할 수 있다. 책은 같은 근육을 쓰는 반복동작을 유해요인으로 분류한다. 하루 작업시간·빈도는 짧은 영상만으로 판단할 수 없다. (책 701, 704~705, 712쪽) |
| 한 손으로 물건을 들고 버티거나 옮기는 자세 | 좌우 팔 위치와 몸통 기울기의 차이를 볼 수 있다. 책은 지지되지 않은 한 손 들기·쥐기를 다룬다. 물건 무게와 실제 쥐는 힘은 사람 확인이 필요하다. (책 701, 706쪽; README 「사람 확인」) |
| 몸통을 돌려 옆의 물건을 집거나 놓는 자세 | 책은 목·허리 비틀림을 부담 자세로 다룬다. 측면 영상만으로 비틀림을 정확히 재기 어려우므로, 이 후보는 사람 확인이 가능한 장면으로만 사용한다. (책 701, 705~706쪽; README 「꼭 지킬 것」) |
| 손목을 꺾은 채 공구를 쥐거나 작은 부품을 집는 자세 | 책은 손·손목의 반복과 집기 작업을 다룬다. 다만 README도 손목 추정이 약하다고 명시하므로, 이 후보는 손목 각도와 쥐는 힘의 자동 판정보다 사람 확인 항목을 검증하는 데 적합하다. (책 701, 704, 706쪽; README 「꼭 지킬 것」) |
| 앉아서 몸통을 숙이거나 팔을 뻗어 작업하는 자세 | 기존 후보는 서거나 쪼그리는 작업에 치우쳐 있다. REBA는 다리의 지지 상태와 상체·팔 자세를 함께 평가한다. README도 앉은 자세의 채점 검증을 요구한다. (책 392쪽; README 「최소 검증 항목」) |
| 한쪽 다리에 체중을 싣거나 발판 위에서 작업하는 자세 | 기존 후보에는 양발 지지가 불안정하거나 좌우 다리의 지지가 다른 장면이 없다. REBA의 다리 자세와 불안정한 지지면을 확인할 수 있다. ([REBA 원 논문](https://doi.org/10.1016/S0003-6870(99)00039-3); [Cornell REBA 채점표](https://ergo.human.cornell.edu/Pub/AHquest/REBAworksheetbw.pdf)) |
| 팔을 옆으로 벌리거나 어깨를 올려 옆쪽 물건을 다루는 자세 | 앞쪽으로 뻗거나 머리 위로 드는 자세만으로는 팔의 벌림·어깨 상승을 확인하기 어렵다. REBA의 위팔 자세 가감 항목을 시험할 수 있다. ([REBA 원 논문](https://doi.org/10.1016/S0003-6870(99)00039-3); [Cornell REBA 채점표](https://ergo.human.cornell.edu/Pub/AHquest/REBAworksheetbw.pdf)) |
| 목이나 몸통을 뒤로 젖히거나 옆으로 기울인 채 작업하는 자세 | 기존 후보는 주로 앞으로 굽히는 자세다. REBA의 목·몸통 평가에는 뒤로 젖힘과 옆 기울임도 관련된다. 측면 영상에서 옆 기울임은 확인이 어려우므로 사람 확인 대상으로 둔다. ([REBA 원 논문](https://doi.org/10.1016/S0003-6870(99)00039-3); README 「꼭 지킬 것」) |
| 카트나 물건을 밀거나 당기는 자세 | 기존 후보는 대부분 물건을 들어 올리는 동작이다. 책은 밀기·당기기도 과도한 힘의 사례로 든다. 영상에서는 자세를 보고 실제 힘의 크기와 손잡이 상태는 사람이 확인해야 한다. (책 582, 586, 716쪽; README 「사람 확인」) |
| 손이나 무릎으로 반복해서 충격을 주는 자세 | 책의 부담작업 사례 중 기존 후보에서 빠진 동작이다. 다만 접촉 충격의 크기와 하루 빈도는 영상 한 편으로 확정할 수 없다. (책 701, 707~708쪽) |
| 팔을 작업대에 지지한 자세와 지지하지 않은 자세 | 같은 팔 각도라도 팔 지지 여부가 REBA의 위팔 가감 점수에 영향을 준다. 두 장면을 비교하면 사람이 확인해야 할 조건이 드러난다. ([REBA 원 논문](https://doi.org/10.1016/S0003-6870(99)00039-3); README 「사람 확인」) |
| 똑바로 서서 팔을 내린 기본 자세 | 굽힘·들기 후보만으로는 중립 자세의 각도와 낮은 점수 처리를 검증하기 어렵다. 책은 REBA가 신체 부위별 자세를 평가한다고 설명하고, README는 목의 중립 보정을 검증 항목으로 둔다. (책 392쪽; README 「꼭 지킬 것」) |

## 후보를 촬영해도 별도로 확인할 평가축

| 평가축 | 현재 후보·영상만으로 부족한 이유 |
| --- | --- |
| REBA의 하중·급격한 힘 증가 | 물건의 실제 무게와 순간적으로 가해진 힘은 영상 픽셀로 측정되지 않는다. 사람이 무게·힘·충격 여부를 입력해야 한다. ([REBA 원 논문](https://doi.org/10.1016/S0003-6870(99)00039-3); README 「사람 확인」) |
| REBA의 손잡이·쥐는 상태 | 손잡이의 형태는 보일 수 있어도 실제로 얼마나 안정적으로 쥐는지는 영상만으로 확정하기 어렵다. 사람 확인이 필요하다. ([REBA 원 논문](https://doi.org/10.1016/S0003-6870(99)00039-3); README 「사람 확인」) |
| REBA의 활동 점수 | 1분을 넘는 정적 자세는 현재 최대 60초 영상만으로 확인할 수 없다. 반복과 급격한 자세 변화도 촬영 구간이 실제 작업을 대표하는지 확인해야 한다. ([Cornell REBA 채점표](https://ergo.human.cornell.edu/Pub/AHquest/REBAworksheetbw.pdf); README 「사용 흐름」) |
| 좌우 차이·팔 지지·비틀림·손목 회전 | 한쪽 팔만 부담을 받거나 팔이 지지되는 경우가 있다. 측면의 2차원 영상은 몸통 비틀림, 팔의 옆 벌림, 손목 회전을 놓칠 수 있다. 평가할 쪽을 지정하고 보이지 않는 가감 조건은 사람이 확인해야 한다. ([REBA 원 논문](https://doi.org/10.1016/S0003-6870(99)00039-3); README 「프론트엔드·엔진 연결 규격」) |
| 책의 부담작업 여부와 조사표 항목 | 키보드·마우스 작업, 손가락 집기, 반복 충격, 접촉스트레스·진동·온도 등은 자세 각도만으로 충분히 평가할 수 없다. 하루 작업시간·횟수, 실제 힘, 작업장 상태, 증상은 현장 확인·면담이 필요하다. 책의 오래된 법령 부록을 현행 기준값으로 사용하지 않는다. (책 701, 712, 716~719쪽; README 「산업안전보건법 기반 기준표 작업」) |
