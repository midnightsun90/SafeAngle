# SafeAngle에 필요한 해커톤 사진 요약

이 문서는 [사진 원문 전사](hackathon-photo-text.md)를 [README의 제품 목표](../README.md)에 맞춰 정리한 참고 자료다. 사진 속 책의 설명을 요약한 것이며, 법적 기준표나 REBA 채점 규칙의 확정본은 아니다.

## 핵심 결론

**SafeAngle은 작업 영상에서 자세가 부담스러운 장면과 REBA 점수의 근거를 보여 주고, 사람이 작업 조건을 확인해 유해요인조사표 초안을 작성하도록 돕는다.** 새 사진 614~623쪽에는 REBA의 부위별 점수, 표 A·B·C, 하중·손잡이·활동 가산점, 최종 조치 수준이 실려 있다. 영상만으로 현장 조사, 근로자 면담, 증상조사까지 끝낼 수는 없다. 결과에는 확인된 정보와 비어 있는 정보를 함께 보여 줘야 한다. (사진 392, 394~396, 583~586, 614~623, 710~716쪽)

## 새 사진에서 추가된 내용

| 사진의 쪽 | 내용 | 이번 제품에서의 처리 |
| --- | --- | --- |
| 594~599 | NLE의 들기 작업 분석, 권장무게한계(RWL)와 들기지수(LI), 적용이 어려운 작업 조건 | REBA 점수와 섞지 않는다. 실제 작업이 들기인지와 하중을 사람이 확인하는 근거로 쓴다. |
| 600~606 | OWAS의 허리·팔·다리·하중 코드와 조치 분류 | 다른 평가법으로 구별한다. SafeAngle의 점수는 REBA로 계산한다. |
| 607~614 | RULA의 상지·목·몸통 자세, 근육 사용·힘, 조치 수준 | REBA와 구별한다. 팔·손목의 가림과 반복 여부를 확인할 필요를 참고한다. |
| 614~623 | REBA의 자세 점수, 표 A·B·C, 하중·손잡이·활동 점수, 1~15점과 조치 수준 | [평가축·점수표](evaluation-axes.md)의 계산 단계 및 경계값과 대조한다. 선택한 장면과 사람 확인값을 함께 기록한다. |
| 624~629 | ANSI-Z 365, Snook's Table, SI, 진동, VDT 등 별도 점검·평가 항목 | 자세 영상이나 REBA 하나로 모든 작업 위험을 평가했다고 표시하지 않는다. |
| 666~667 | 증상·징후 신고 이후의 확인과 후속 조치 | 앱의 조사표 초안과 실제 증상 관리 절차를 구별한다. 증상은 근로자·현장 담당자가 확인한다. |

## 제품 흐름에 연결하기

| 단계 | 사진에서 얻은 내용 | SafeAngle에 적용할 내용 |
| --- | --- | --- |
| 영상 분석 | 작업 장면을 관찰·촬영해 자세와 부담을 평가한다. REBA는 전신 자세를 부위별로 평가하고 표 A·B·C를 거쳐 최종 점수를 낸다. (389, 392, 395, 614~623쪽) | 대표 장면과 시각, 목·몸통·팔·손목·다리의 자세, 각도와 점수 근거를 보여 준다. 측정하기 어려운 부위는 확인 필요로 남긴다. |
| 사람 확인 | 조사에는 작업시간·빈도, 취급 물체와 힘, 작업방법 등의 정보가 필요하다. (394~396, 584~586, 714~716쪽) | 하중·손잡이·활동 조건 등 REBA 입력값을 사람이 확인·수정한다. 영상에 안 보이는 조건을 임의로 채우지 않는다. |
| 조사표 초안 | 기본조사는 작업장 상황과 작업조건을 기록한다. 면담과 증상조사는 별도 절차다. (584~588, 712~718쪽) | 영상에서 얻은 자세 근거를 초안에 넣고, 공정·설비·작업량·증상 등 확인되지 않은 칸은 비워 둔다. 조사자가 편집하고 확인한다. |
| 개선안 | 공구·설비·작업공간을 바꾸는 방법과 작업일정·속도·회복시간을 조정하는 방법이 있다. (397~399쪽) | AI가 제안하는 개선안을 `설비·도구·작업공간`과 `작업방식·시간`으로 정리하고, 현장 적용 여부는 사람이 결정한다. |

## 조사표 초안에 필요한 정보

| 묶음 | 필요한 항목 | 주된 입력 경로 |
| --- | --- | --- |
| 기본 정보 | 조사 구분·일시·조사자, 부서·공정·작업명 | 사용자 입력. 사진 584, 714쪽 |
| 작업장 상황 | 설비, 작업량, 작업속도, 최근 업무·공정 변화 | 현장 확인·면담. 사진 394, 396, 584, 712, 714쪽 |
| 작업조건 | 작업내용, 작업시간·빈도·부하, 반복, 부적절한 자세, 과도한 힘, 접촉스트레스, 진동, 온도·조명 등 | 자세의 일부는 영상, 나머지는 현장 확인·면담. 사진 396, 585~586, 715~716쪽 |
| 증상과 이력 | 통증 부위·기간·강도·빈도, 최근 증상, 근무 이력 등 | 근로자 본인의 증상조사·면담. 영상으로 추정하지 않음. 사진 587~588, 717~718쪽 |
| 개선계획 | 공정·작업, 문제점과 원인, 개선방향, 일정·비용, 해당 근로자 의견 | 조사자와 현장 관계자가 검토. 사진 398~399쪽 |

기본조사표와 증상조사표에는 개인 건강정보가 포함된다. 현재 README의 범위는 **편집 가능한 조사표 초안**이며, 증상이나 과거 병력을 영상 또는 AI가 채운 것처럼 표시하지 않는다. (사진 587~588, 717~718쪽)

## 결과 화면에서 구별할 세 가지

1. **REBA 자세 평가:** 선택한 장면의 자세·점수·근거와 사람이 확인한 채점 조건. 새 사진에는 표 A·B·C와 조치 수준이 있다. 책의 표와 REBA 원자료를 대조해 채점 규칙을 확정한다. (사진 388, 392, 614~623쪽)
2. **법령상 적용 조건:** 작업시간·횟수·무게 등 영상 밖의 조건까지 확인해야 하는 항목. 사진의 701~708쪽에는 부담작업 범위와 해설이 있지만, 그대로 현행 법령으로 사용하지 않는다.
3. **영상 측정 품질:** 관절 가림 등으로 각도를 믿기 어려운지 표시하는 앱의 판단. 법적 기준이나 REBA 점수와 섞지 않는다. ([README](../README.md))

## 이 사진을 사용할 때 주의할 점

- 사진 698~713쪽에는 과거 법령·고시와 해설이 실려 있다. 서로 다른 시기의 문구도 보인다. **기준값과 조사 시기·방법을 제품에 넣기 전** [산업안전보건기준에 관한 규칙 제657조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1028543325), [제658조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020911757), [관련 고시](https://www.law.go.kr/행정규칙/근골격계부담작업의범위및유해요인조사방법에관한고시)의 **적용 버전과 원문**을 확인한다. 확인한 결과는 README에서 예정한 `docs/criteria.md`에 출처·시행일·확인일과 함께 기록한다.
- REBA는 자세 평가의 한 도구다. 사진의 조사 흐름은 기본조사, 증상조사, 위험 평가, 개선, 효과 확인까지 이어진다. **REBA 점수만으로 법정 유해요인조사가 완료됐다고 안내하지 않는다.** (사진 583, 710~711쪽)
- 사진에는 NLE·OWAS·RULA·JSI/SI·ANSI-Z 365·Snook's Table 등 다른 평가법도 나온다. 이번 제품 범위는 README대로 REBA이며, 다른 평가법의 계산 기능을 추가한다는 뜻은 아니다. (사진 388~393, 594~614, 624~629쪽)
- `해커톤 대시보드.jpg`는 별도 화면 이미지다. 안전 기준이나 조사표의 출처로 사용하지 않는다.

## 팀이 바로 활용할 부분

- **엔진:** 대표 장면의 부위별 각도·점수·근거와 사람이 확인한 조건을 구분해 전달한다. 사진 614~623쪽의 REBA 점수표와 원자료를 대조해 계산을 검증한다.
- **프론트엔드·기준표:** 위 조사표 항목을 `영상에서 관찰`, `사람 확인`, `현장·증상조사`로 표시하고, 공식 원문을 확인한 법령 조건만 기준표에 넣는다.
- **조사표:** 확인되지 않은 칸과 조사자 검토 상태를 남긴다. 개선안은 현장 검토를 거쳐 수정 가능한 제안으로 표시한다.
