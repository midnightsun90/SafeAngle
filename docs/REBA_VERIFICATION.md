### 실제 브라우저에서 실행한 실패·상태 사례

- 회사 정보 → 영상 1/2/3 → 평가 화면까지 선택한 실제 File 전달.
- 실제 업무에 없는 촬영 유형 건너뛰기, 영상 2의 파일 한 편만으로 평가 진입.
- 충격을 미확인으로 되돌리면 확정 점수 제거, 다시 확인하면 갱신.
- 손잡이 해당 없음은 확인된 +0, 손목 확인 불가는 확정 점수 없음.
- 장면·쪽 변경 시 이전 답변·점수 제거. 먼 쪽의 팔 측정 실패는 null 유지, 보이는 부위 구간을 사람이 확인한 경우만 보충. 확인 불가로 바꾸면 점수 제거.
- 사람이 없는 검정 영상 **10장면**, 두 사람이 보이는 파생 영상 **10장면**: 채점 질문 진입 차단.
- 진행 중 취소 후 실제 재분석 성공. 첫 동기 추론 중 취소 지연 안내 표시.
- 새 파일에서 답변·결과 제거, 손상된 MP4 오류 후 실제 영상으로 복구.
- 세 영상에서 독립 답변·결과 유지, 마지막 짧은 영상 **10장면** 실제 재분석.
- 결과 요약·상세 평가서로 같은 시각·쪽·점수·사람 입력 전달. 미평가 영상 점수 없음, 평가 화면 복귀 시 오래된 확정 결과 제거.
- 실제 업무에 없는 영상 1을 생략해도 영상 2 번호를 유지. 예시 사진과 실제 영상의 흐름 분리.
- 모델 GET 200과 **9,398,198바이트**, 존재하지 않는 파일 404, 경로 탈출 요청 403 확인.

부분 관절의 `invalid_landmarks`를 전체 장면 실패로 오인하지 않는 회귀 테스트도 추가했다. 반대쪽 개별 실패는 선택한 쪽을 차단하지 않는다. 전체 좌표 누락·다중 인물·추적 검토 등 전역 품질 실패는 사람 답으로 덮지 않는다.

## 재현

Node.js 24 이상, 설치된 Chrome, 파생 영상 준비용 FFmpeg가 필요하다. 저장소 루트에서 실행한다.

```powershell
npm ci
npm --prefix frontend ci
npm run prepare:fixtures
npm test
npm run typecheck
npm --prefix frontend run typecheck
$env:GITHUB_PAGES='true'
npm --prefix frontend run build
$env:VERIFY_BASE_PATH='/SafeAngle'
npm run reba:verify
```

`prepare:fixtures`는 [기존 엔진 검증](ENGINE_VERIFICATION.md)의 출처·이용 조건·해시를 유지한다. 모델은 공식 Full float16 v1이며 SHA256은 `5134a3aad27a58b93da0088d431f366da362b44e3ccfbe3462b3827a839011b1`이다.

원본 영상은 [RickyBennison의 Basic single leg squat](https://commons.wikimedia.org/wiki/File:Basic_single_leg_squat.webm), CC BY-SA 4.0이다. 검증은 **공개 원본 한 편과 그 파생 영상**으로 진행했다. 검정·복제·짧은·손상 파일은 실패 흐름용이며 별도의 사람 정확도 표본이 아니다. 원본과 파생 영상, 실제 결과 JSON, 스크린샷은 `.local/`에 두고 Git에 넣지 않는다.

최종 브라우저 결과는 `.local/reba-verification/results.json`, 화면 증거는 같은 폴더의 `real-video-score.png`, `video-overlay.png`, `real-report.png`, `mobile.png`다. **14개 브라우저 시나리오 기록**은 여러 반복 분석·상태 확인을 묶은 수이며 사람 정확도 표본 수가 아니다. 모델·각도·품질·양쪽 측정의 기존 검증은 [ENGINE_VERIFICATION.md](ENGINE_VERIFICATION.md), 공유 채점 계약·경계 정책은 [REBA.md](REBA.md)에 있다.

## 확인하지 않은 것

- **관절 좌표·각도 정확도, 사람 독립 채점과의 일치율**. 질문 입력은 연결 검증용 시나리오이며 독립 정답 라벨이 없다. 위 5→6점은 정확도나 정답 일치율 주장이 아니다.
- 실제 사업장의 작업 영상과 현장 촬영, 목 중립 보정, 손가락 관절·비틀림의 자동 판정.
- Safari·iPhone 실기기와 코덱, 실제 GitHub Pages 서비스·접근 권한·네트워크 환경.
- 생성형 API, 유해요인조사 전체 및 법적 부담작업 해당 여부. 화면과 결과 계약에서 미완료·미확인으로 유지한다.
- **MediaPipe의 대회 허용 여부**. 대표가 포크된 세션에서 운영진에게 확인한다. 이번 실행 성공은 규정상 허가를 뜻하지 않는다.

현재 검증한 완료 범위는 실제 웹의 **한 장면 → 사람 확인 → REBA 점수·근거** 연결이다.
