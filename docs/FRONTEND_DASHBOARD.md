# 프론트엔드 명세: 대시보드와 평가 대상자

상태: 구현 전 명세 · 2026-10-09

## 목적과 용어

기존 평가 흐름을 대시보드 안에서 시작하고, 평가 대상자별로 찾을 수 있게 한다. 첫 진입 때 입력하는 이름은 **평가자 이름**, `평가 추가` 때 입력하는 이름은 **평가 대상자 이름**이다. 이름 입력은 로그인이나 본인 확인이 아니다.

## 화면 흐름

1. 첫 방문에는 대시보드가 보이되 흐리게 처리한다. 가운데에 `이름을 입력해 주세요` 입력창과 `시작하기` 버튼을 띄운다. 이름이 비어 있으면 진행할 수 없다.
2. 평가자 이름을 입력하면 흐림이 사라지고 대시보드를 사용할 수 있다. 빈 대시보드에는 평가가 없다는 짧은 안내와 `평가 추가` 행동을 보여 준다.
3. 왼쪽 사이드바 맨 위에 `평가 추가` 버튼을 둔다. 그 아래에 추가한 평가 대상자 이름을 한 줄씩 보여 준다. 현재 선택한 사람은 주황색으로 구별한다.
4. `평가 추가`를 누르면 가운데에 평가 대상자 이름 입력창과 `평가 시작` 버튼을 띄운다. 이름이 비어 있으면 만들지 않는다.
5. `평가 시작`을 누르면 해당 대상자를 선택하고 기존 첫 화면인 `회사·작업 정보`를 연다. 이후 영상 선택, 영상 확인, 질문, 분석, 결과 요약, 상세 평가서까지 기존 순서를 유지한다. 평가 중에도 사이드바에서 대상자와 `평가 추가`에 접근할 수 있다.
6. 사이드바 아래 또는 오른쪽 위의 평가자 프로필을 누르면 `로그아웃` 메뉴가 열린다. 로그아웃하면 익명 세션과 브라우저의 임시 평가 정보를 비우고 첫 이름 입력 화면으로 돌아간다. 서버의 평가 기록은 삭제하지 않는다.

## 화면 구성

- 데스크톱: 좁은 왼쪽 사이드바와 넓은 본문. 사이드바에는 SafeAngle, `평가 추가`, 평가 대상자 목록만 둔다. 본문에는 대시보드 또는 현재 평가 단계를 표시한다.
- 모바일: 목록을 여닫을 수 있게 하고, 평가 본문은 기존처럼 한 열로 표시한다.
- 기존 `design/design.md`의 흰 배경, 차콜 글자, 회색 선, 주황색 기본 버튼, 넉넉한 여백을 따른다. 해당 문서의 `사이드바 없음`은 기존 평가 입력 화면 기준으로 두고, 이번 요청에 따라 대시보드 틀에만 사이드바를 추가한다.
- 흐림은 첫 이름 입력 중인 대시보드 본문에만 적용한다. 입력창은 흐리지 않고 선명하게 보인다. 키보드 초점은 입력창 안에 두며, 배경의 버튼은 이름 입력 전까지 조작할 수 없다.

## 정보와 상태

- 평가자: 화면에서 부를 이름 1개. 현재 프론트엔드에서는 **해당 브라우저에 임시 저장**해 재방문 시 첫 입력을 생략한다. 이름은 계정이나 관리자 권한이 아니다. Supabase 연결 전에는 다른 기기와 동기화되지 않는다.
- 평가 대상자: 목록에 표시할 이름, 서로 구분할 내부 ID, 생성 순서, 현재 진행 단계. 동명이인은 이름만으로 합치지 않는다.
- 한 평가 대상자는 기존 평가 흐름의 입력값과 결과를 가진다. 다른 사람을 선택해도 앞 사람의 회사·작업 정보, 영상 선택, 답변, 결과가 섞이면 안 된다.
- 사이드바에서 이전 대상자를 누르면 마지막 진행 단계로 돌아가 저장된 회사·작업 정보, 선택 장면, 질문 답변, 결과를 이어서 본다. 이 정보는 해당 브라우저에 대상자별로 저장한다.
- 영상 파일 자체는 저장하지 않는다. 새로고침하거나 브라우저를 다시 열어 영상 파일이 사라졌다면 기존 파일이 필요한 단계에서 재선택을 안내한다. 재선택 전에는 영상·장면·결과가 정상 연결된 것처럼 표시하지 않는다.
- 자세 분석은 브라우저에서 처리한다. 현재 프론트엔드는 원본 영상을 서버에 저장하지 않는다. 별도로 준비된 Supabase 비공개 영상 저장소와의 연결은 이 화면 구현에 포함하지 않는다. 대표 장면의 외부 전송은 별도 동의 이후에만 가능하다.
- 현재 구현은 회사·작업 정보 일부만 브라우저에 저장하고, 선택한 `File` 영상과 질문 답변은 메모리에 둔다. 구현 시 대상자별 저장과 복원으로 바꿔야 한다.

## 기존 화면과 연결

| 현재 화면 | 대시보드 적용 후 |
| --- | --- |
| `/` 회사·작업 정보 | 대시보드 첫 화면으로 전환. 평가 대상자 생성 후 회사·작업 정보로 이동 |
| `/upload/1`~`/upload/3` | 선택한 대상자의 영상 선택 |
| `/review`, `/questions/...`, `/analysis` | 선택한 대상자의 기존 평가 단계 |
| `/results`, `/report` | 선택한 대상자의 결과와 상세 평가서 |

`예시 사진으로 화면 둘러보기`는 실제 평가 대상자를 만들지 않는 데모로 유지한다. 데모 점수를 실제 대상자 결과로 저장하거나 목록에 표시하지 않는다. 현재 제품 화면의 점수는 엔진 연결 전이므로 확정 점수처럼 표현하지 않는다.

## 완료 기준

1. 첫 방문에 이름 입력창이 보이고, 입력 후 대시보드가 선명해진다.
2. 평가 대상자를 추가하면 사이드바에 이름이 나타나고 해당 사람의 기존 첫 평가 화면이 열린다.
3. 대상자를 다시 선택하면 저장된 진행 단계와 입력값이 복원되고, 다른 대상자의 정보가 섞이지 않는다.
4. 데모는 실제 평가 목록과 구분된다.
5. 모바일에서도 이름 입력, 평가 추가, 기존 평가 진행이 가능하다.
