## 출력과 검수

브라우저에서 `deck.html`을 열고 PDF 인쇄한다. 배경 그래픽 켜기, 여백 없음, 머리글·바닥글 끄기. CSS 페이지 크기를 적용한다. 전체 17장, 16:9, 이미지와 한글 잘림을 확인한다. PDF에서는 영상이 재생되지 않는다.

서체는 Pretendard 1.3.9 고정 WOFF2 Regular/Bold다. 폰트와 라이선스는 `assets/fonts/`에 보관한다. 제목 54px, 주요 본문 30~32px, 주석 21px이며 통계 숫자는 더 크게 사용한다. 최종 제출 조건은 현장 안내와 `docs/HACKATHON.md`를 따른다.

조사 기간은 사업장 조사 전체의 표본평균이며 제품 처리 시간이나 절감률이 아니다. 5년 보존은 KOSHA 기술적 권고다. 현재 제품의 정확도·절감 시간·구매 의향은 현장 검증 전이다.

검증 근거는 `SafeAngle-engine/docs/VLM_VERIFICATION.md`와 `.local/vlm-verification/results.json`, GPT 연결 커밋 `8c61b15`다. 제품 엔진과 팀 통합은 다른 세션에서 진행 중이다. 덱 작업은 테스트 재실행이나 공개 배포 확인을 하지 않았다. 현재 단일 대표 장면 GPT 제안 방식이며 연속 추적·자동 최악 자세 탐색으로 소개하지 않는다.

전체를 임팩트 버전으로 바꾸되 조사 표본·기술적 권고·사람 확인·검증 범위는 남겼다. 상세 근거는 발표 노트의 본선용 부분과 sources.md에 보존한다. 현재 15장은 실패 대응, 16장은 Codex 활용이다. 이전 16장 버전은 백업 폴더에서 복원할 수 있다.


여백이 큰 1·2·3·10·11·14·15·16·17장의 주요 글자를 확대했다. 브랜드명 132~148px, 해당 제목 66~76px, 세 역할·실패 대응 본문 40px다. 문구·장 순서·대본은 유지했으며 사진·통계 장의 기존 크기와 롤백 백업은 보존했다.

## 실제 배포 화면 반영 (10/9)

11장은 공개 배포 웹앱의 관절 표시, 12장은 상세 평가서의 항목별 판정 요약, 13장은 실제 점수·위험 수준·조치 필요 결과를 사용한다. 출처는 엔진 `.local/live-flow/overlay.png`, `report.png`, `results.json`이다. 2026-10-09 16:24 KST 기록에서 실제 인증·비공개 영상 업로드·GPT 호출·REBA 5점·저장 및 재접속 복원이 확인되며 요청 모킹은 없다. 이번 덱 수정에서는 API를 재호출하지 않았다. 과거 로컬 캡처 교체 안내는 이 기록으로 대체한다.

## PDF 이미지 반영

12장은 실제 저장한 상세평가서 PDF 2페이지의 항목별 판정 요약이다. 15장은 PDF 1페이지의 관절 확인 기록을 확대해 index_mcp의 관측 불가와 사람 확인 기록을 보여 준다. 출처: 엔진 `.local/pdf-verification/report.pdf`, `print-1.png`, `print-2.png`. 누락은 기록하고 사람의 확인을 요구하며, 확인 후 점수가 생성되는 흐름이다. 관측 불가가 한 개라도 있으면 영구적으로 채점을 거부한다고 설명하지 않는다.
