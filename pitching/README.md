## 출력과 검수

브라우저에서 `deck.html`을 열고 PDF 인쇄한다. 배경 그래픽 켜기, 여백 없음, 머리글·바닥글 끄기. CSS 페이지 크기를 적용한다. 전체 15장, 16:9, 이미지와 한글 잘림을 확인한다. PDF에서는 영상이 재생되지 않는다.

서체는 Pretendard 1.3.9 고정 WOFF2 Regular/Bold다. 폰트와 라이선스는 `assets/fonts/`에 보관한다. 제목 54px, 주요 본문 30~32px, 주석 21px이며 통계 숫자는 더 크게 사용한다. 최종 제출 조건은 현장 안내와 `docs/HACKATHON.md`를 따른다.

조사 기간은 사업장 조사 전체의 표본평균이며 제품 처리 시간이나 절감률이 아니다. 5년 보존은 KOSHA 기술적 권고다. 현재 제품의 정확도·절감 시간·구매 의향은 현장 검증 전이다.

검증 근거는 `SafeAngle-engine/docs/VLM_VERIFICATION.md`와 `.local/vlm-verification/results.json`, GPT 연결 커밋 `8c61b15`다. 제품 엔진과 팀 통합은 다른 세션에서 진행 중이다. 덱 작업은 테스트 재실행이나 공개 배포 확인을 하지 않았다. 현재 단일 대표 장면 GPT 제안 방식이며 연속 추적·자동 최악 자세 탐색으로 소개하지 않는다.

최종 다듬기에서는 발표 화면의 내부 경로·커밋 SHA·캡처 교체 메모를 자료 성격 중심의 문구로 바꿨다. 원본 근거·범위·남은 교체 항목은 sources.md와 speaker-notes.md에 유지한다. 15장 구성과 발표 내용은 보존했다.
