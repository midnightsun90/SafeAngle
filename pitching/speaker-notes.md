# SafeAngle 발표 대본 초안

목표: 4분 안에 공감, 문제 규모, 담당자의 반복 업무, 제품, 구매 이유를 전달한다. 15장. 2026-10-09 대표의 피칭 예행연습에서 4분 소요를 확인했다(대표 보고). 아래 장별 시간은 기존 설계 참고치이며 합계 3분 50초다. 내용과 순서는 예행연습한 구성을 유지한다.

## 1 · 표지 · 6초
SafeAngle은 작업 영상에서 자세를 확인하고, 평가 점수와 근거를 정리하는 웹앱입니다. 솔로연합입니다.

## 2 · 해커톤 속 우리의 자세 · 10초
어.. 이거 난가? 지금 이 방에서 저희 팀원이 작업하는 모습입니다. 몰입하다 보면 자세를 의식하지 못합니다. 우리에게도 익숙한 장면에서 시작했습니다.

대표가 제공한 실제 팀원 사진이다. 질환을 진단하는 자료가 아니다.

## 3 · 산업 현장 · 8초
산업 현장에서는 들고, 숙이고, 반복하는 동작이 매일의 작업입니다. 이 자세와 작업 조건을 확인하는 일이 필요합니다.

설명용 AI 생성 이미지다. 실제 재해나 위험 등급 판정 장면으로 소개하지 않는다.

## 4 · 문제 규모 · 10초
2025년 산재 승인 통계에서 신체부담작업으로 분류된 질병재해자는 1만 4,185명입니다. 전체 질병재해자의 41.9%, 열 명 중 약 네 명입니다.

출처: 고용노동부 2025년 산업재해 현황. 분모 33,825명, 승인일 기준. https://www.korea.kr/docViewer/result/2026.03/31/198418718/198418718.files/24.html

## 5 · 조사 기간 · 12초
기업은 이를 조사하고 개선해야 합니다. 2023년 연구에서 기간 문항에 답한 51개 사업장의 유해요인조사 전체 기간은 평균 20.5일이었습니다. 작업 자세의 평가와 확인도 그 과정의 일부입니다.

사업장 조사 전체의 표본평균이다. 순수 노동시간, 한 영상의 채점 시간, 전국 사업장 평균으로 바꾸지 않는다. SafeAngle이 20.5일을 줄인다고 주장하지 않는다.
출처: 산업안전보건연구원(2023), 근골격계질환 유해요인조사제도 개선 방안 연구 p.46. https://www.aposho.org/oshri/publication/researchReportSearch.do?articleNo=448394&attachNo=253286&mode=download

## 6 · 반복 의무와 기록 · 12초
근골격계부담작업이 있는 사업장은 의무적으로 정기 유해요인조사를 해야 하고, 법정 사유가 생기면 수시조사도 검토해야 합니다. KOSHA는 조사 결과와 의학적 조치 기록의 5년 보존을 권고합니다. 조사와 근거 정리가 반복되는 업무입니다.

정기조사는 법적 의무, 5년 보존은 기술적 권고다. 발표에서는 주기 숫자를 생략하며, 정확한 법정 주기는 sources.md와 공식 제657조를 따른다. 모든 문서나 원본 영상의 법정 보관 의무로 표현하지 않는다. 현재 제품이 5년 저장 기능을 구현했다고 주장하지 않는다.
법령: https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1028543325
KOSHA GUIDE E-G-1-2025 제10장: https://www.aposho.org/kosha/info/koshaGuideData.do?articleNo=453891&attachNo=261185&mode=download#page=43

## 7 · 실무자 부담 한눈에 요약 · 15초
실무자는 조사 방법을 판단하고, 작업마다 평가하고, 근거를 남겨야 합니다. 2023년 연구에서 사업장 조사 전체는 평균 20.5일, 비용은 평균 약 305만원이었습니다. 이 조사와 기록 관리가 반복됩니다.

기간 n=51, 비용 n=44의 서로 다른 응답 표본이다. 비용 평균 304.8만원, 표준편차 539.5만원, 범위 0~2,000만원, 0원 응답 17개소다. 모든 사업장에 같은 비용이 발생하거나 한 작업의 채점에 305만원이 든다고 주장하지 않는다. 30.3%는 어려움 문항 27/89개소의 복수응답이다. 제품이 해당 기간·비용을 전액 절감한다고 설명하지 않는다.
출처: 산업안전보건연구원(2023) 근골격계질환 유해요인조사제도 개선 방안 연구 p.46~47·51~52. https://www.aposho.org/oshri/publication/researchReportSearch.do?articleNo=448394&attachNo=253286&mode=download

## 8 · 평가 단계의 반복 업무 · 10초
영상을 찍어도 평가는 남습니다. 장면을 고르고, 부위별 자세를 보고, 작업 조건을 기준과 대조합니다. 점수를 계산하고 근거까지 기록합니다. 같은 연구에서는 어려움 문항 응답 사업장의 30.3%가 적절한 조사 방법을 모른다고 답했습니다.

27/89개소, 복수응답, 2023년 연구 p.51–52. 전국 비율이나 비전문가 비율로 바꾸지 않는다. 모든 사업장이 수기 평가를 한다고 주장하지 않는다.

## 9 · GPT 판단과 사람·코드의 역할 · 25초
GPT에는 사람이 고른 대표 장면 한 장과 평가할 쪽, 몸 방향을 전달합니다. GPT는 그쪽의 8개 관절 좌표를 제안합니다. 사람이 원본 위에서 확인하고 수정하며, 목·손목과 작업 조건도 확인합니다. 그 뒤 코드가 각도와 REBA 표를 계산합니다. 보이지 않는 관절은 추측값으로 채우지 않습니다.

제품 AI는 이미지의 관절 좌표 제안에 사용한다. GPT가 점수·무게·작업시간·의료 진단을 직접 출력한다고 설명하지 않는다. 전체 영상 자동 분석·최악 자세 탐색·연속 추적은 현재 기능이 아니다. 8개 관절 요청과 전체 관절 인식 성공은 다르다.
근거: `lib/vlm/prompt.ts`, `docs/VLM_TRANSITION.md`, `lib/reba/score.ts`. 모델 ID는 실제 구현의 gpt-6.1-sol이다.

## 10 · 제품 흐름 · 30초, 시연 포함
GPT API의 비전언어모델, VLM으로 대표 장면을 분석합니다. 이미지와 지시문을 함께 전달해 선택한 쪽의 관절 좌표를 제안받습니다. 사람이 원본 위에서 확인한 뒤, 코드가 각도와 REBA 점수를 계산합니다.

현재 `assets/gpt-overlay.png`는 실제 GPT 응답을 원본에 표시한 로컬 화면이다. 최종 제품 캡처 교체 위치는 product-flow다. 단일 장면 시연이며 연속 추적 화면으로 소개하지 않는다. 실제 호출 3회 평균 24.817초 기록이 있어 시연은 미리 받은 실제 응답과 라이브 호출 대기 시간을 구분해 준비한다. 캐시·녹화는 그 사실을 공개한다.

## 11 · 결과와 근거 · 20초, 시연 포함
평가서에는 대표 장면과 GPT 원 제안, 사람이 수정한 좌표를 함께 남깁니다. 어떤 입력이 점수로 이어졌는지를 확인할 수 있습니다. 사람이 최종 판단합니다.

`assets/gpt-report.png`는 실제 GPT 연결의 로컬 상세 평가서다. product-report에서 관절 확인 기록을 보여 준다. 최종 화면 제공 시 교체한다. 현재 공개 API 배포·법정 조사표 전체 완료는 검증되지 않았다.

## 12 · 구매와 도입 · 20초
여러 사업장을 평가하는 조사 대행기관과 보건관리전문기관을 첫 고객으로 보고 있습니다. 평가자는 영상과 조건을 확인하고 결과를 검토합니다. 기관 단위 구독을 가정하고, 반복 확인과 기록에 드는 시간과 구매 의향부터 검증하겠습니다.

구매·운영 가설이다. 기관 단위 구독은 이번 피치의 제안이며 확정한 요금제가 아니다. 구매 의향·절감 시간·가격·API 호출 비용은 실증 전이다. 근골격계질환 예방 성과나 법적 준수 보장으로 말하지 않는다.

## 13 · 검증과 실패 대응 · 20초
실제 공개 영상 한 장면을 세 번 호출했을 때 검지 관절은 모두 보이지 않았고, 고관절 좌표도 차이가 있었습니다. 누락은 그대로 남기고 사람이 확인합니다. 좌표를 바꾸면 이전 점수는 지우고, 필수 입력이 확인 불가하거나 API가 실패하면 점수를 확정하지 않습니다.

실제 영상 1편·2초 장면·480×640 JPEG, 같은 요청 3회. 검지 MCP 0/3, 고관절 최대 두 응답 거리 9.03px. 이것은 반복 안정성이고 정답 대비 정확도가 아니다. 방향을 잘못 고른 초기 3회 시나리오는 별도로 기록했으며 위 반복 표에 섞지 않았다.
검증 기록: 엔진 69개·프론트 상태 8개 테스트 통과, REBA 240칸 대조와 기준 예제 11점. 이번 덱 작업에서 테스트를 다시 실행하지 않았다. 결과 JSON과 문서 기록을 읽고 반영했다.
all-null·503·취소는 통제한 실패 응답으로 확인했으며 OpenAI 실서비스에서 모두 실제 발생했다고 주장하지 않는다. 독립 정답·산업 현장 영상·절감 효과는 아직 없다.

## 14 · Codex 활용 과정 · 22초
Codex에 GPT API와 입력 검증, 좌표 검토 화면, 각도와 REBA 계산 연결을 맡겼습니다. 팀 기준표와 실제 API 응답으로 검토하고, 누락·좌표 수정·취소 시 점수가 남지 않도록 확인했습니다. 팀 프론트의 기존 흐름을 보존하며 통합하고 테스트와 빌드 기록을 남겼습니다.

개발 도구 Codex와 제품 모델 GPT의 역할을 구별한다. 참고 구현 커밋 8c61b15의 30개 파일 변경, 팀 기준표, VLM 검증 문서와 실제 결과 JSON이 근거다. 후속 팀 통합이 진행 중이므로 최종 제출 SHA·실행 상태·Codex 로그와 대조한다. 사전 설계와 당일 구현의 출처는 제출 기록대로 공개한다. 전체 과거 작업을 Codex가 썼다고 소급 주장하지 않는다.

## 15 · 마무리 · 10초
위험을 보고, 근거를 남기다. 작업 영상 기반 근골격계 위험 평가, SafeAngle입니다. 솔로연합이었습니다.
